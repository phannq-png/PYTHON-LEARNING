# LỘ TRÌNH PHÁT TRIỂN TƯƠNG LAI (FUTURE ROADMAP)
## Dự án: TranslatorApp

TranslatorApp v1.0 đã đặt nền móng vững chắc cho việc dịch thuật chuyên ngành. Dưới đây là các tính năng dự kiến cho các phiên bản tiếp theo (Phase 5+).

---

## 🚀 Phase 5: Hiệu suất & Cộng tác (Performance & Collaboration)

### 5.1 Xử lý Hàng loạt (Batch Processing)
- Cho phép người dùng chọn cả một thư mục tài liệu.
- Tự động dịch và export tất cả file trong hàng đợi.

### 5.2 Chế độ Review Chuyên nghiệp (Review Mode)
- Trạng thái trang: "Draft" -> "Review" -> "Verified".
- Cho phép người dùng đánh dấu các đoạn cần AI dịch lại theo phong cách khác.

### 5.3 Đồng bộ Đám mây (Cloud Sync)
- Tích hợp Google Drive API để lưu trữ Glossary và Sessions trực tuyến.
- Chia sẻ bộ thuật ngữ dùng chung cho đội nhóm.

---

## 🧠 Phase 6: AI Nâng cao (Advanced AI Integration)

### 6.1 Tích hợp OCR (Optical Character Recognition)
- Hỗ trợ dịch trực tiếp từ file PDF scan hoặc hình ảnh chụp tài liệu.
- Sử dụng Google Vision API hoặc Tesseract.

### 6.2 Chấm điểm Chất lượng (Quality Scoring)
- Sử dụng model AI thứ 2 (ví dụ: GPT-4o chấm điểm Gemini-1.5) để đánh giá độ chính xác của bản dịch so với glossary.

### 6.3 Fine-tuning Model
- Cho phép người dùng "huấn luyện" AI bằng cách học từ các bản sửa lỗi thủ công của người dùng (Learning from feedback).

---

## 📱 Phase 7: Đa nền tảng & Hệ sinh thái (Multi-platform)

### 7.1 Web-based Interface
- Xây dựng phiên bản Web (Next.js/React) sử dụng cùng logic Core API.

### 7.2 Plugin cho Microsoft Word
- Tích hợp trực tiếp các tính năng glossary và AI vào thanh Ribbon của MS Word.
