# Release Notes - v1.1.0 (2026-05-09)

Phiên bản này tập trung vào việc cải thiện trải nghiệm người dùng (UX) và tối ưu hóa quy trình nhập thuật ngữ hàng loạt theo yêu cầu của Project Owner.

## 🚀 Các tính năng mới & Nâng cấp

### 1. Giao diện & Trải nghiệm (UI/UX)
- **Loading Spinner Dạng Card**: Chuyển đổi overlay toàn màn hình sang dạng Card nổi (Toplevel) ở chính giữa. Người dùng có thể nhìn thấy nội dung màn hình chính phía sau khi đang xử lý.
- **Khởi động Maximized**: Ứng dụng tự động khởi động ở chế độ phóng to trên Windows.
- **Highlight Thuật ngữ**: Cải tiến tính năng highlight trong văn bản, hỗ trợ tìm kiếm không phân biệt chữ hoa/thường (`nocase=True`).

### 2. Nhập thuật ngữ hàng loạt (Bulk Import AI)
- **✨ Làm sạch thông minh**: Nút làm sạch dữ liệu giờ đây hỗ trợ tách (split) theo cả dấu cách thường và dấu cách Nhật (`　`), chỉ lấy phần văn bản cuối cùng làm thuật ngữ.
- **Prompt Rules Tùy chỉnh**: Thêm ô nhập liệu "Yêu cầu bổ sung" để người dùng đưa ra các quy tắc dịch thuật ưu tiên cho AI.
- **Quy tắc mặc định**: Tích hợp sẵn bộ quy tắc dịch thuật kỹ thuật (ví dụ: `部材` -> "linh kiện").
- **Cấu trúc Prompt Nghiêm ngặt**: Cập nhật mẫu prompt 3 phần (Task, Rules, JSON Format) cho cả Gemini và OpenAI để đảm bảo kết quả chính xác 100%.

### 3. Quản lý Thuật ngữ (Glossary Manager)
- **Xóa tất cả (Delete All)**: Thêm nút xóa toàn bộ thuật ngữ cho từng tab lĩnh vực kèm hộp thoại xác nhận an toàn.

## 🛠️ Sửa lỗi kỹ thuật
- **Lỗi Tkinter Crash**: Khắc phục lỗi `bad stickyness value "center"` trong cửa sổ kiểm tra nhất quán.
- **Lỗi Font Weight**: Sửa lỗi khai báo font weight không hợp lệ trong CustomTkinter.
- **Duplicate Prompt Logs**: Loại bỏ việc in trùng lặp nội dung prompt trong terminal.

## 📦 Kỹ thuật & Cấu trúc
- Cập nhật `BaseAIClient` để hỗ trợ truyền tham số yêu cầu bổ sung (`additional_reqs`).
- Lọc thuật ngữ thông minh: Chỉ gửi các thuật ngữ có trong context trang hiện tại để tối ưu hóa API call.
