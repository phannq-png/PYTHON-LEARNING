# Release Notes: v1.0.0 (First Production Release) 🏁
**Ngày phát hành**: 2026-05-08

Phiên bản 1.0.0 đánh dấu sự hoàn thiện toàn bộ các tính năng cốt lõi và nâng cao của TranslatorApp, biến nó thành một ứng dụng dịch thuật chuyên ngành Nhật-Việt chuyên nghiệp và tin cậy.

---

## 🌟 Tính năng Chính (Main Features)

### 1. Engine Dịch AI Thế hệ Mới
- Tích hợp **Google Gemini 1.5 Pro/Flash** và **OpenAI gpt-4o**.
- Khả năng **ép buộc thuật ngữ (Glossary Enforcement)** cực kỳ mạnh mẽ trong prompt.
- Tự động phát hiện lĩnh vực tài liệu (Domain Detection) bằng AI.

### 2. Xử lý Văn bản Bảo toàn Định dạng
- Cơ chế trích xuất và áp dụng metadata định dạng 100%.
- Giữ nguyên Font, Màu sắc, Bảng, Danh sách trong file Word sau khi dịch.
- Hỗ trợ xuất file song ngữ (Bilingual) thông minh.

### 3. Hệ thống Quản lý Thuật ngữ Toàn diện
- Quản lý đa lĩnh vực với cơ chế ưu tiên (Priority merging).
- **Bulk Import**: Dịch và nhập hàng loạt thuật ngữ bằng AI với UI xử lý xung đột.
- Xuất/Nhập CSV hỗ trợ tốt nhất cho Excel.

---

## 🎨 Trải nghiệm Người dùng (UX/UI)
- **Modern Dark Mode**: Giao diện xám đậm hiện đại với màu nhấn Blue/Amethyst.
- **Design System**: Thống nhất bo góc 10px toàn bộ ứng dụng.
- **Interactive Sidebar**: Highlight thuật ngữ và cuộn văn bản tức thì.
- **Feedback**: Hệ thống thanh tiến trình chi tiết và thông báo Toast nhẹ nhàng.

---

## 🛠️ Cải tiến Kỹ thuật (Technical Improvements)
- Kiến trúc 4 lớp (UI - Core - Data - Service) tách biệt hoàn toàn.
- Hệ thống Logging xoay vòng tự động bảo vệ dữ liệu log.
- Mã hóa API Key bằng thuật toán Fernet (cryptography).
- Cơ chế Auto-save (5 phút) và Startup Resume bền bỉ.
