## Mô tả

### Mục đích
Xây dựng lớp vỏ ngoài (Main Window) của ứng dụng bằng CustomTkinter, bao gồm việc chia bố cục (Menu Bar, Top Bar, Left Sidebar, Center Panel, Right Sidebar, Bottom Bar) theo đúng mô tả.

### Phạm vi
**Làm:**
- [ ] Khởi tạo `app_window.py` với cấu trúc cửa sổ chính (min 1200x800).
- [ ] Tạo **Menu Bar** (dùng `tk.Menu`) với cấu trúc:
  - `File`: Open, Exit
  - `Settings`: Segmentation Settings, API Settings
  - `Help`: About
- [ ] Tạo **Top Bar**: chứa nút Upload File, Dropdown chọn lĩnh vực, nút Export (placeholder).
- [ ] Chia các panel chính: Sidebar trái, Panel giữa (chia ngang trên/dưới), Sidebar phải.
- [ ] Tạo **Bottom Bar**: chứa placeholder cho các nút thao tác và token counter.
- [ ] Theme mặc định là Dark mode.

**KHÔNG làm:**
- Gắn logic gọi API (chỉ làm UI tĩnh).
- Implement nội dung Dialog của Settings (sẽ làm ở P1-CONF-002).

### Acceptance Criteria
- [ ] AC1: Chạy app hiển thị đúng khung cửa sổ, có thể resize (min 1200x800).
- [ ] AC2: Menu Bar hiển thị đúng 3 mục: File, Settings, Help với các submenu tương ứng.
- [ ] AC3: Top Bar hiển thị đúng: nút Upload, Dropdown lĩnh vực, nút Export.
- [ ] AC4: Panel ở giữa chia làm 2 phần trên/dưới cho tiếng Nhật (read-only) và tiếng Việt (editable).
- [ ] AC5: Click "Settings > Segmentation Settings" và "Settings > API Settings" không bị lỗi (có thể chỉ hiện placeholder dialog).

### Technical Notes
- Dùng `tk.Menu` (từ tkinter gốc) để tạo Menu Bar — CustomTkinter chưa có widget Menu riêng.
- Dùng `customtkinter.CTkFrame` và hệ thống `grid`/`pack` để layout các panel còn lại.
- Menu Bar gắn vào cửa sổ bằng `root.config(menu=menubar)`.
