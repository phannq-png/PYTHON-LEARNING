## Mô tả

### Mục đích
Cung cấp phản hồi trực quan cho người dùng về tiến độ thực hiện của các thao tác mất nhiều thời gian, giúp tăng trải nghiệm người dùng và tránh cảm giác ứng dụng bị treo.

### Phạm vi
**Làm:**
- [ ] Implement một component `ProgressIndicator` có thể tái sử dụng (sử dụng `CTkProgressBar`).
- [ ] Tích hợp thanh tiến trình cho các thao tác:
    - Upload và xử lý file DOCX ban đầu.
    - Quá trình gọi API dịch (hiển thị khi nhấn nút Translate).
    - Quá trình dịch hàng loạt (Bulk Import).
    - Quá trình tạo file export DOCX.
- [ ] Hiển thị phần trăm (%) và văn bản trạng thái (ví dụ: "Đang dịch trang 5/10...").
- [ ] Vô hiệu hóa các nút bấm tương tác trong khi quá trình đang chạy để tránh xung đột.

**KHÔNG làm:**
- Chỉnh sửa logic xử lý chính của các tính năng (chỉ thêm phần hiển thị tiến độ).

### Acceptance Criteria
- [ ] AC1: Khi nhấn Translate, một thanh tiến trình xuất hiện và cập nhật theo từng trang dịch.
- [ ] AC2: Khi export file lớn, thanh tiến trình hiển thị đúng % hoàn thành.
- [ ] AC3: Các nút bấm (Save, Translate, Export) bị mờ đi (disabled) khi đang có một tiến trình chạy.
- [ ] AC4: Sau khi tiến trình kết thúc, thanh tiến trình biến mất hoặc reset, các nút bấm hoạt động trở lại.

### Technical Notes
- Sử dụng `CTkProgressBar` của CustomTkinter.
- Cần sử dụng cơ chế `threading` hoặc `after()` của Tkinter để cập nhật UI mượt mà mà không làm treo main thread.
- Văn bản trạng thái nên được cập nhật linh hoạt tùy theo ngữ cảnh thao tác.

## Implementation Guide

### Input
- `progress_value` (float): Giá trị từ 0.0 đến 1.0.
- `status_text` (str): Nội dung thông báo trạng thái.

### Output
- Giao diện thanh tiến trình được cập nhật trên UI (thường nằm ở `BottomBar` hoặc một modal dialog).

### Algorithm/Logic
1.  **Khởi tạo**: Đặt `CTkProgressBar` vào vị trí phù hợp (ví dụ: góc dưới bên trái của `BottomBar`). Mặc định ẩn (`grid_forget`).
2.  **Bắt đầu tiến trình**:
    - Gọi `progress_bar.grid()` để hiển thị.
    - Set `progress_bar.set(0)`.
    - Vô hiệu hóa các nút điều khiển chính.
3.  **Cập nhật**:
    - Các hàm xử lý (dịch, export, v.v.) sẽ gọi hàm `update_progress(current, total, text)` sau mỗi bước hoàn thành.
    - Hàm này tính toán `current/total` và gọi `progress_bar.set()`.
4.  **Kết thúc**:
    - Ẩn thanh tiến trình.
    - Kích hoạt lại các nút điều khiển.
