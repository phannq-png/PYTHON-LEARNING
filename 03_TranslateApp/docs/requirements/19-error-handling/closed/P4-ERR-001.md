## Mô tả

### Mục đích
Xây dựng hệ thống xử lý lỗi tập trung để đảm bảo ứng dụng không bị crash bất ngờ, cung cấp thông báo lỗi dễ hiểu cho người dùng và ghi lại log chi tiết để phục vụ việc bảo trì.

### Phạm vi
**Làm:**
- [ ] Implement một class `Logger` tập trung (sử dụng thư viện `logging` của Python).
- [ ] Ghi log lỗi vào file `data/logs/error.log` với đầy đủ timestamp, loại lỗi và stack trace.
- [ ] Thiết lập cơ chế xoay vòng log (log rotation) khi file vượt quá 10MB.
- [ ] Xây dựng các decorator hoặc context manager để bắt lỗi tại các điểm quan trọng (API calls, File I/O).
- [ ] Thống nhất cách hiển thị thông báo lỗi trên UI thông qua `CTkMessagebox`.

**KHÔNG làm:**
- Ghi các thông tin nhạy cảm (API Key, nội dung tài liệu của người dùng) vào log.

### Acceptance Criteria
- [ ] AC1: Khi xảy ra lỗi (ví dụ: mất mạng khi dịch), một thông báo thân thiện hiện lên UI thay vì treo ứng dụng.
- [ ] AC2: Mọi lỗi xảy ra đều được ghi lại vào file `error.log` với đầy đủ thông tin kỹ thuật.
- [ ] AC3: File log không vượt quá dung lượng cho phép và tự động xoay vòng.
- [ ] AC4: Thông tin trong log không chứa dữ liệu nhạy cảm của người dùng.

### Technical Notes
- Sử dụng `logging.handlers.RotatingFileHandler` để xử lý việc xoay vòng file log.
- Cần phân biệt rõ giữa `INFO`, `WARNING`, `ERROR`, và `CRITICAL` levels.
- Đảm bảo việc ghi log không làm giảm hiệu năng đáng kể của ứng dụng.

## Implementation Guide

### Input
- Các ngoại lệ (exceptions) được ném ra từ các module khác.
- Thông tin ngữ cảnh tại thời điểm lỗi.

### Output
- File `data/logs/error.log` được cập nhật.
- Dialog thông báo lỗi hiển thị trên UI.

### Algorithm/Logic
1.  **Cấu hình Logger**:
    - Khởi tạo `logging.getLogger("TranslatorApp")`.
    - Thêm `RotatingFileHandler` với `maxBytes=10*1024*1024` và `backupCount=5`.
    - Thiết lập định dạng log: `%(asctime)s - %(name)s - %(levelname)s - %(message)s`.
2.  **Centralized Catching**:
    - Tạo một hàm tiện ích `show_error(message, details=None)`.
    - Hàm này vừa gọi `logger.error(details)` vừa gọi `CTkMessagebox(title="Lỗi", message=message, icon="cancel")`.
3.  **Tích hợp**:
    - Bao bọc các khối mã nguy hiểm bằng `try...except`.
    - Trong khối `except`, gọi `show_error`.
