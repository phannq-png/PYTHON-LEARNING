# Quy tắc quản lý thư mục Requirements

Mỗi feature sẽ có một thư mục riêng với định dạng: `[số thứ tự]-[tên-feature]`.
Trong mỗi thư mục feature sẽ có:
- `opening/`: Chứa các file markdown của các task đang chờ xử lý hoặc đang làm.
- `closed/`: Chứa các file markdown của các task đã hoàn thành.

Tên file task: `[ID_Task].md` (ví dụ: `P1-DOC-001.md`).
