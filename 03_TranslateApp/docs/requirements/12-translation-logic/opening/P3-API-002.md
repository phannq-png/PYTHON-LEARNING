## Mô tả

### Mục đích
Kích hoạt tính năng dịch tự động bằng AI khi người dùng nhấn nút "Translate" ở Bottom Bar.

### Phạm vi
**Làm:**
- [ ] Kết nối sự kiện Click nút "Translate" từ `BottomBar` tới `AppWindow`.
- [ ] Thu thập dữ liệu cần thiết: Text tiếng Nhật (hiện tại), Glossary (domain đã chọn), API Key (từ ConfigManager).
- [ ] Khởi tạo `TranslationEngine` và gọi hàm `translate`.
- [ ] Xử lý callback `on_success`: Cập nhật kết quả vào `CenterPanel` (Textbox VN) và lưu vào `current_session`.
- [ ] Xử lý callback `on_error`: Hiển thị thông báo lỗi lên UI (vd: dùng messagebox).
- [ ] Hiển thị trạng thái "Loading" hoặc disable nút trong khi chờ API.

### Acceptance Criteria
- [x] AC1: Nhấn Translate trang hiện tại sẽ hiển thị bản dịch tiếng Việt sau vài giây.
- [x] AC2: Nội dung dịch được lưu lại vào Session (có thể kiểm tra bằng cách chuyển trang và quay lại).
- [x] AC3: Nếu API Key sai, app hiển thị lỗi mà không bị crash.
