## Mô tả

### Mục đích
Sử dụng AI để phân tích nội dung văn bản nhằm tự động gợi ý hoặc thiết lập lĩnh vực (Domain) phù hợp. Hỗ trợ cả chế độ tự động khi nạp file và kích hoạt thủ công qua giao diện.

### Phạm vi
**Làm:**
- [x] Xây dựng prompt chuyên biệt để AI nhận diện lĩnh vực bằng **tiếng Việt** (ví dụ: Y tế, Công nghệ thông tin, Pháp luật).
- [x] **Tự động nhận diện**: Kích hoạt ngay sau khi nạp file DOCX.
    - Nếu trùng lĩnh vực cũ: Tự động chọn.
    - Nếu lĩnh vực mới: Hiển thị Dialog gợi ý người dùng.
- [x] **Kích hoạt thủ công**: Thêm nút **✨** cạnh dropdown lĩnh vực ở TopBar.
    - Khi nhấn nút: AI phân tích trang hiện tại.
    - Nếu lĩnh vực mới: **Tự động tạo và chọn** (không hiện popup xác nhận).
- [x] Hiển thị thông báo "Toast" ở BottomBar khi đang xử lý và khi hoàn tất.

**KHÔNG làm:**
- Tự động dịch toàn bộ glossary. Chỉ tạo vỏ lĩnh vực mới.

### Technical Notes
- Prompt yêu cầu AI trả về tiếng Việt, ngắn gọn (1-3 từ), viết hoa chữ cái đầu.
- Sử dụng 5000 ký tự đầu tiên để phân tích.
- Phân biệt luồng: Tự động (hiện Popup) và Thủ công (Tự động tạo).

## Implementation Details (English Version Summary)

### Goal
Use AI to analyze text content and automatically suggest or set the appropriate Domain. Supports both auto-detection on file upload and manual trigger via UI.

### Scope
- **AI Prompt**: Configured to return domain names in **Vietnamese** (e.g., "Y tế", "Công nghệ thông tin").
- **Manual Trigger**: Added a ✨ button in the TopBar.
- **New Domain Handling**:
    - **Manual Flow**: Automatically create and select the new domain (silent).
    - **Auto Flow (Upload)**: Suggest via a popup dialog.
- **Feedback**: Bottom bar toast notifications for "Processing" and "Success".

### Acceptance Criteria

- [x] AC2: AI detects new domain -> system creates JSON and selects it automatically (Manual mode).
- [x] AC3: File upload -> Popup suggests domain (Auto mode).
