## Mô tả

### Mục đích
Xây dựng module Core/Logic xử lý gọi API dịch thuật (Google Gemini và OpenAI). Hệ thống cần tự động sinh prompt dựa trên văn bản tiếng Nhật nguồn, thuật ngữ (glossary) của lĩnh vực hiện tại và context.

### Phạm vi
**Làm:**
- [ ] Tạo class `TranslationEngine` ở `src/core/translation_engine.py`.
- [ ] Implement hàm gọi Google Gemini API (dùng `google-generativeai`).
- [ ] Implement hàm gọi OpenAI API (dùng `openai`).
- [ ] Logic sinh Prompt: Nhúng text nguồn, danh sách thuật ngữ từ `GlossaryRepository` vào prompt.
- [ ] Hàm bắt lỗi (timeout, invalid key) và trả về thông báo hợp lý thay vì crash app.
- [ ] Chạy API call trên một thread riêng biệt (hoặc async) để không làm treo giao diện UI chính.

### Acceptance Criteria
- [ ] AC1: Có thể dịch thành công 1 đoạn text bằng Gemini nếu cung cấp key đúng.
- [ ] AC2: Có thể dịch thành công 1 đoạn text bằng OpenAI nếu cung cấp key đúng.
- [ ] AC3: Giao diện (UI) không bị treo/đứng trong thời gian chờ API trả kết quả.
- [ ] AC4: Nếu truyền API Key sai hoặc mất mạng, hệ thống bắt được lỗi và trả về chuỗi thông báo lỗi.

### Technical Notes
- Có thể dùng `threading.Thread` hoặc `concurrent.futures` để bọc lệnh gọi API.
- Cần có cơ chế callback để khi API trả về kết quả, `TranslationEngine` có thể bắn event để UI cập nhật vào Textbox tiếng Việt.
